

# Krelavo Store

### Tu belleza, tu esencia.

## Descripción

Krelavo Store es un proyecto académico de una tienda virtual enfocada en productos de belleza, cuidado facial y cuidado capilar.

El proyecto inició con el diseño de un prototipo interactivo en Figma y continuó con el desarrollo de una aplicación de escritorio utilizando Java.

## Objetivo

Desarrollar una aplicación que permita explorar un catálogo de productos de belleza mediante una interfaz sencilla y organizada.

## Funcionalidades

- Inicio de sesión.
- Visualización del catálogo de productos.
- Búsqueda de productos.
- Filtros por categoría, marca y precio.
- Selección de productos favoritos.
- Contador de productos agregados al carrito.

## Tecnologías utilizadas

- Java 8.
- JavaFX 8.
- NetBeans.
- Apache Ant.
- Figma.
