# Tienda Krelavo

### Tu belleza, tu esencia.

## Descripción

Krelavo Store es un proyecto académico de una tienda virtual enfocada en la comercialización de productos de belleza, cuidado facial y cuidado capilar.

El proyecto comenzó con el diseño de un prototipo interactivo en Figma y continuó con el desarrollo de una aplicación de escritorio utilizando Java y JavaFX.

## Objetivo

Desarrollar una aplicación que permita explorar un catálogo de productos de belleza, gestionar compras y administrar la información de la tienda mediante una interfaz sencilla, organizada y agradable para el usuario.

## Funcionalidades

### Módulo de clientes
- Registro de usuarios e inicio de sesión.
- Visualización del catálogo de productos.
- Búsqueda de productos.
- Filtros por categoría, marca y precio.
- Selección y gestión de productos favoritos.
- Carrito de compras con modificación de cantidades.
- Proceso de compra y registro de pedidos.
- Consulta del historial de compras.
- Edición de información personal.
- Gestión de direcciones.
- Cambio de contraseña.

### Módulo de administración
- Panel principal con información general de la tienda.
- Gestión de productos.
- Administración de categorías y marcas.
- Control de inventario.
- Registro de entradas y ajustes de existencias.
- Consulta de movimientos de inventario.
- Consulta de pedidos y clientes.
- Visualización de reportes.

## Tecnologías utilizadas

- **Java 8:** lenguaje de programación.
- **JavaFX 8:** desarrollo de la interfaz gráfica.
- **SQLite:** gestión de la base de datos.
- **Apache Ant:** automatización de la compilación.
- **NetBeans:** entorno de desarrollo.
- **Figma:** diseño del prototipo interactivo.
- **Git y GitHub:** control de versiones y almacenamiento del proyecto.
